# Skill Nexis Week 3 - Python & Data Wrangling

## Objective
Clean and analyze a messy dataset using Python and Pandas.

## Dataset
The dataset contains workout-related information including Duration, Date, Pulse, Maxpulse and Calories.

## Tasks Completed
- Loaded the CSV dataset using Pandas
- Inspected dataset structure and data types
- Identified missing values
- Handled missing Date and Calories values
- Removed duplicate records
- Identified an unusual Duration value
- Filtered rows using conditions
- Created new columns
- Created data visualizations
- Exported the cleaned dataset

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Files
- data.csv - Original dataset
- cleaned_data.csv - Cleaned dataset
- Week_3_Python_Data_Wrangling.ipynb - Complete analysis
